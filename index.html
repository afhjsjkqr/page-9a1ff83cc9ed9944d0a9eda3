如何从零开始配置？

依照以下三个步骤完成订购、凭证导入与日常访问验证。

01

第一步：你适合哪种配额等级？

首先评估你的日常流量消耗与主力设备数量。轻量浏览用户推荐选用基础版；若需多设备协同或更丰富的节点分类，旗舰版提供了更为均衡的吞吐容量；小型工作组则可直接使用团队版规划集中订阅。

02

第二步：如何获取并同步订阅链接？

完成账户订购后，在用户控制面板生成通用格式的订阅地址。将该链接粘贴至受支持的客户端软件中执行更新，节点列表与路由分流策略将自动完成同步，无需逐个手动输入服务器参数。

03

第三步：连接状态如何排查与维稳？

若遇到连接无响应的情况，可先尝试刷新订阅配置文件或切换备选节点。建议同时关注客户端本地的系统代理开关及时间同步状态，保持设备时钟与网络标准时间一致有助于认证正常运作。

多平台客户端该怎样配合使用？

梦兰网络订阅协议兼容市面上主流的通用代理客户端，请依照你所处的操作系统获取相应开源或第三方应用。

Windows 桌面端

支持基于 Clash、Sing-box 或 v2rayN 内核的通用客户端。导入订阅 URL 后开启系统代理即可接管网页流量。

macOS 环境

可选用 Clash Verge、Surge 或 Loon 等客户端，按需设定基于域名的增强路由规则，适配多网卡切换。

Android 移动端

推荐使用 Clash Meta for Android 或 v2rayNG。支持根据应用层设置分应用代理，有效节约移动流量消耗。

iOS / iPadOS

可通过 Shadowrocket、Loon 或 Quantumult X 导入订阅凭证。利用移动配置文件便捷实现按规则智能分流。

常见疑问与解答

点击展开各条目查看详细处理方法与使用边界说明。

超过套餐内设定的“同时在线设备数”会怎样？
当处于并发连接状态的设备数量超出所订购套餐的限额（如基础版 3 台、旗舰版 5 台、团队版 20 台）时，超出限制的新连接可能会发生鉴权拒绝或促使较早的连接断开。建议固定主力设备使用，避免外部分享。
每个月的流量重置日是固定日期还是按账单周期计算？
梦兰网络的流量配额按照你的实际激活订购日进行周期循环。若你在当月 15 日订购，流量会在次月 15 日自动重置为初始配额，未用完的流量不予结转至下一个账期。
什么是 IPLC 专线优化与原生流媒体解锁？
旗舰版与团队版包含的专线节点采用点对点直连链路，减少了公网抖动对实时游戏和音视频传输的影响；原生流媒体解锁则指针对特定平台的区域版权服务提供对应的原生网络出口。
若节点出现大面积不可用，应首先通过何种渠道排查？
请优先进入后台确认账号的订阅状态是否欠费或流量超额；随后测试本地网络 DNS 是否受到污染。旗舰版及团队版用户如遇故障，可直接通过用户中心提交 7x24 工单联系值守支持。
